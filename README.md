# Computer Manager

**Computer Manager** is a web dashboard for IT equipment management. It allows administrators to manage computers, hardware components, and users, while providing inventory reports, status change history, and data visualizations to support informed decision-making.

## Tech Stack

- Vue 3, TypeScript, Vite, Pinia, Vue Router, Tailwind CSS

## Prerequisites

- **Node.js**: `^20.19.0` or `>=22.12.0`

## Getting Started
```sh
git clone <https://github.com/EAFIT-Works/pc-manager>
cd pc-manager
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Other Commands
```sh
npm run build       # Production build
npm run type-check  # TypeScript check
npm run lint        # Lint and fix
npm run format      # Format code
```
